# 日日記帳

記錄餐飲、交通、水電、購物等日常開銷的單檔 PWA。

## 功能
- 8 種分類：餐飲、交通、水電、購物、居家、醫療、娛樂、其他
- 金額可輸入 `120+85` 自動加總
- 月總覽：總支出、預算進度、日均、較上月增減
- 分類占比，點分類可篩選明細
- 依日期分組的明細，點一筆可編輯或刪除
- 備份：複製 JSON 備份、貼上還原、複製當月 CSV
- 可加入主畫面，離線使用

## 資料
資料存在瀏覽器 localStorage（`ririjizhang.v1`），只在這台裝置上。換手機或清除瀏覽資料前請先到設定複製備份。

## 部署
GitHub Pages：Settings → Pages → Source 選 `main` / root。
